# 策划稿 · 小红书图文「爷青回」

一篇借 IG 冲世界赛热度的**情怀软广**。目标不是讲清楚《破晓》是什么，
是让一批八年前看过 S8 的人停下来、看完、留言——游戏只在第 8、9 张图露面。

出图工程在 `promo/xhs/`，改文案改 `content.json`，跑两条命令就重新出图。

---

## 一、选题逻辑

热点是 IG 打进世界赛的希望，TheShy 和 Rookie 带队，情绪词是「爷青回」。

这个热点和《破晓》有一条天然的暗线：

- 现实里 S12~S15 的冠军是 DRX、T1、T1、T1，四年没回来过；
- 游戏里这四年**照抄真实历史**，S16 是空的，没有剧本。

所以这篇的叙事是「**现实的遗憾 → 游戏里那一年还空着**」，
不是「我做了个游戏快来玩」。后者发出去必沉。

## 二、内容配比：9 张图里游戏只占 2 张

判断标准只有一条：**这篇图文就算把第 8、9 张删掉，也值得被点赞收藏。**

- 图 1~7 一个游戏元素都不许出现，用户是被这七张留下来的
- 图 8 才第一次提到游戏，措辞是「顺便说一句」「打发时间写的」
- 图 9 给网址，放在角落，不做全屏 CTA 卡
- 正文里游戏只占三行，而且写在括号里

前七张是内容，后两张是彩蛋。比例一旦反过来，这篇就变成广告帖。

## 六、标签

`#英雄联盟 #爷青回 #IG战队 #TheShy #Rookie #S8 #LPL #电竞 #青春 #情怀`

前四个吃热点流量。**这篇一个游戏类标签都不要带**——
带了系统会把它分进游戏推广池，情怀池的量大一个量级。

## 七、评论区才是转化口

正文里不放网址（放了压流量）。链路是这样的：

1. 图 9 角落的小字网址，留给认真看完九张图的人
2. 等真人来问「什么游戏」「求链接」，一条条回：
   `www.poxiao.lol，浏览器直接打开，免费，手机电脑都行`
   每回一条都是一次曝光，还能把评论区顶活
3. 问的人多了，再置顶一条「统一回一下：网址 www.poxiao.lol」
4. **不要一发出去就自己置顶广告**——那一刻这篇就从情怀帖变成广告帖

## 八、图片来源与版权守则

游戏是免费的、无内购无广告，页脚也写了「个人非商业同人作品」，
这是用真实赛事照片时最大的护身符。在这个前提下：

**可以用**

- **lolesports 官方 Flickr**（`flickr.com/photos/lolesports`）——Riot 官方赛事摄影号，
  很多图挂的是知识共享「署名-非商业」协议。**逐张点开确认许可证**再下载，这是最干净的来源。
- **Riot / LPL 官方微博、lolesports.com** 的赛事图，用时标 `© Riot Games`
- **战队官微自己发的夺冠图**（IG 官微），转发或引用 +@ 来源
- 想要某张特定的图，直接私信摄影师要授权

**不要碰**

- **视觉中国 / Getty 带水印的图**——国内维权最凶的就是这类，非商用也照告
- 其他自媒体二次加工过的图（等于抄两层）

**三条自保规则**

1. 每张真实照片角落标 `© Riot Games`（模板已经内置这个位置）
2. 不要把真实选手的脸 P 进游戏 UI，不要做「XX 推荐」「XX 同款」——那是暗示代言
3. 尾图写明「个人非商业同人作品 · 与 Riot Games 及各俱乐部无关」（模板已内置）
4. 这篇图文里不挂任何付费入口

## 九、出图工程用法

```bash
cd promo/xhs
# 1. 把六张真实照片按 photos/README.md 的文件名放进 photos/
# 2. 生成 HTML（改了 content.json 也跑这条）
node build.mjs
# 3. 渲染成 1080×1440 的 PNG，输出到 out/
node render.mjs
```

没放照片的卡片会渲染成一个虚线占位槽，槽里写着这张要什么图、去哪找、怎么裁——
**所以第一次出的图可以直接当找图清单用**。照片放进去再跑一次就是成品。

渲染需要 playwright：`npm i -D playwright && npx playwright install chromium`。

字体按 `PingFang SC → Microsoft YaHei → Noto Sans CJK SC` 依次回退，
在 Mac / Windows 上出图会比在 Linux 上更接近你现有几张宣传图的观感。

## 十、发布与复盘

- 时间：晚 8~11 点
- 封面认第一张，情绪要「燃 + 怀旧」，别做成游戏广告图
- 发布后两小时内守着评论区，问链接的每条都回
- 看三个数：**封面点击率**（决定标题和图 1 行不行）、
  **完播到第 9 张的比例**（决定这个软广结构行不行）、
  **评论里问链接的条数**（决定这篇值不值得再发一条同结构的）

如果这篇跑通了，同结构可以复用到：EDG S11、RNG MSI、Uzi 退役——
每个都是一个「现实有遗憾 + 游戏里那年空着」的选题。
