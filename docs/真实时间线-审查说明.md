## 难度调整（作者已选：卫冕被研究 +1.5）

作者反馈：「目前游戏难度偏低，有从 S13–S19 连续七年夺冠的玩家」。2026-09-11 作者认可推荐方案，按本节「实现了什么」做完，定稿批测在本节最后。

**先量现状**（各 120 局，含再战三年；「连续 N 年」= 每个赛季至少拿一座冠军，联赛 / MSI / 世界赛都算）：

| | 线上 普通 | 线上 强 | 时间线（没调难度）普通 | 时间线 强 |
|---|---|---|---|---|
| 生涯场均冠军 | 5.49 | 9.13 | 6.23 | 10.55 |
| 连续 ≥5 年有冠军 | 21% | 40% | 19% | 42% |
| 连续 ≥7 年有冠军 | 5% | 13% | 3% | 18% |

**摸排出来的关键杠杆**：
1. **你打比赛时，对手按「五个人的数值」算战力**：默契、战术、士气、真实胜率加成都没算进去（只有 AI 打 AI 才算），你这边却全套都算。赛前预览里显示的对手战力倒是带加成的——预览和实际对不上。
2. **「冠军班底」可以一直续**：每拿一座国际冠军就续一年（战力 +4/+5、默契不回落、队友不走）。
3. **没有任何针对卫冕冠军的阻力**。

**试过的方案**（时间线版，各 120 局含再战；「S16 前」三项只数 S12–S16）：

| 方案 | 普通：S16 前 MSI / 世界赛 | 普通：生涯场均冠军 | 普通：连续≥5 年 | 普通：S14 国际冠军数 | 强：S16 前 MSI / 世界赛 | 强：生涯场均冠军 | 强：连续≥7 年 |
|---|---|---|---|---|---|---|---|
| 不改 | 18% / 32% | 6.23 | 19% | 9 | 42% / 59% | 10.55 | 18% |
| **卫冕被研究 +1.5（推荐）** | 11% / 22% | 4.58 | 10% | 3 | 27% / 33% | 7.59 | 9% |
| 对手整队加成算一半 | 8% / 23% | 4.17 | 5% | 0 | 24% / 44% | 7.99 | 5% |

- **卫冕被研究**：你近一年（本赛季 + 上赛季）每拿一座冠军，所有对手打你时 +1.5 战力，封顶 +4。**第一座冠军不受影响**，拿得越多越被针对——专压连冠。生涯冠军数两档都降到线上版本以下，连冠比例减半。
- **对手整队加成**：凡是算进去的方案，普通玩家 S14 的国际冠军都掉到 0–1 座（120 局），和节奏表「S14 首冠」冲突。
- **冠军班底不续期**几乎无效：时间线里你的队每年按真实名单换人，「3 个夺冠队友还在」这个条件本来就经常断。
- 不管选哪个，赛前预览里的对手战力都要和实际算法对齐（现在预览带加成、实际不带），并在预览里写出「卫冕压力 +X」。

### 实现了什么

- **卫冕压力**（`squad.ts` 的 `defendPressure`）：本赛季 + 上赛季你生涯里记下的每一座冠军（联赛 / MSI / 世界赛），你比赛里的每个对手战力 +1.5，封顶 +4。只进你自己的比赛——判定胜负、临场决策前后的赢面、赛后结算都算；AI 打 AI 不受影响。
- **预览和实际对齐**（`oppMatchPw`）：下一场卡片、备战页、行动卡底下「本周对手」那一行、世界页赛程表，原来显示的是对手**带默契战术的整队战力**，比赛里判定用的却是**五个人的实力加权**——现在这几处全部显示判定用的那个数。所以**这几处的对手战力会比原来低一截：不是对手变弱了，是原来多写了。**
- **卫冕压力单独标**：比分页、下一场卡片、备战页在对手战力旁边用红字写「卫冕压力 +X」，鼠标停上去写「本赛季和上赛季你拿了 N 座冠军，对手都在研究你」；赛程表下面写一行说明；叙事模式下，下一场卡片写「卫冕压力 ↑」。没拿冠军时不出现。
- **老存档也生效**：难度调整不分新老档（和时间线只对新档不同）。如果作者想只给新档，改一行。
- **自检**：新增单元检查——没冠军 / 两个赛季前的冠军 / 1 座 / 2 座 / 3 座分别是 0 / 0 / +1.5 / +3 / +4；下一场预览有压力时写出来，没有时不写。

- **和拍板时的试验逐字节一致**：同种子 1001–1120、含再战三年，普通 / 强玩家各 120 局，统计输出和上表「卫冕被研究 +1.5」那一行的原始结果文件**逐字节相同**——上线的代码和试的是同一个东西；预览对齐只改显示，不动任何结果。
- 所以数字就是上表那一行：普通玩家 S16 前 MSI 11% / 世界赛 22%、生涯场均冠军 4.58、连续≥5 年有冠 10%、S14 国际冠军 3 座（120 局）；强玩家 27% / 33%、7.59、连续≥7 年有冠 9%。

- **读法：国际冠军被压下来了，联赛冠军没动。** 卫冕压力只在你拿过冠军之后才加，所以「至少拿一座」（大多是联赛冠军）和线上持平甚至更高；拿了联赛冠军再去打 MSI / 世界赛，才开始被研究。强玩家「任一冠军 +3.4σ」是换成真实数据时就有的，难度调整不管第一座。

## 一句话

**新开的档照旧从 2022 年（S12）开局**；从 S12 结束后的休赛期开始，每年把世界换成下一年真实的首发名单（2023、2024、2025、2026 各一页），赛区结构按真实改制；你所在的队也跟真实名单走（你的位置和你亲手造成的变动除外）。难度用现行版本的标定曲线锁住——换的是人，不是难度。**老存档一切照旧。**

## 为什么

玩家反馈：「时间线都 S15 了还只是 S12 的选手，没有新人」。原因是世界只用了 2022 年一份快照，之后全靠模拟老化和编出来的新秀。现行版本探针：S15 的 LPL 85 个首发里 79 个还是 2022 年的人，T1 到 S19 只换掉了 Faker（换成编的 Woongi）。

   - 2026：LTA 拆回 LCS 与 CBLOL；LPL 缩编到 14 队；**LDL 停办**。

## 平衡怎么锁的（换脸不换难度）

- **标定**：现行版本跑 240 局（普通/强各 120，含再战三年），记录每个联赛在「世界年龄」0–7 时的首发五维均值、离散、默契、战术。世界年龄 = 这份世界被推过几年（签约时新建的世界从 0 算——现行版本就是这样，晚签约的人面对的是新建的世界）。
- **换页时**：联赛五维**均值和离散**都锚到标定值（明星放大照开局那份 anchorLeague）；默契/战术延续原队、按换人数扣分，再整体回中到标定值；真实胜率按现行的年度回归系数折算。

### 第一版批测没过，查出来三个病因（都修了）

第一版只锚了均值：同种子 240 局，普通玩家场均冠军 2.46 → **1.12**、世界赛 .308 → **.113**；强玩家 4.30 → 2.35。世界最强队并没有变强，掉的是**你所在的队**。逐年诊断（120 局，每个赛季开季记一次你的队）找到三个原因：

1. **你的队默契被真实转会砸穿**。真实名单每年换掉你 2.6–3.1 个队友，每换一个人砸 7.5 默契（这是给赛季中途换人设计的），几年滚下来 S15 开季默契 30 → **10**，战力 71.4 → 65.2。
   - 修：休赛期的真实换人有整个季前赛来磨，**不砸默契**（`TL_SWAP_SYN = 0`；赛季中途换人仍走原来的整额；新队友的信任和关系照常从「不熟」起步）。A/B：系数 0.4 时普通玩家世界赛 .317 → .167，0.15 时 MSI 仍 −1.7σ，0 时六项冠军率都回到 1.6σ 以内。
   - 修：真实转会进来的人**不低于他顶替的那位队友**（`TL_ARRIVAL_FLOOR`）——你带着这支队攒下的底子，不因为真实转会凭空消失。不加这条（只打折默契）普通玩家联赛冠军仍掉到 .583。
2. **真实名单的明星更扎堆**。只锚均值时 LCK / LEC / LCS 的首发离散比现行世界大 1–2.5 分，LCK 前四战力 +1～1.6。修：离散也锚到同一世界年龄的标定值。
3. **名望地板每年抬回原位**。开局那份（2022）给 Faker 87、Chovy 85 这类地板是一次性的，现行版本里他们之后跟着年龄曲线衰退；真实页每年都抬回去，T1 / Gen.G / HLE 一直顶在 85+。修：地板按「现行版本里他今年该衰退到哪」算（Faker 2023–2026：85.3 → 82.8 → 80.0 → 77.0），只降不升。

- 普通玩家全部在 2σ 内；**强玩家换成真实比赛数据之后偏易**（MSI、任一冠军超过 2σ）。这张表是**还没调难度**时的数字；加上「卫冕被研究」之后的 240 局定稿见「难度调整 → 实现后的批测」。
- **噪声参考**：同一套规则只挪一个随机事件的时机，两次 240 局就能晃 ±0.05。
- **逐年分布（节奏表「S14 首冠」）**：换成比赛数据后，普通玩家 S14 世界赛冠军 11 → 12 次（240 局），和线上持平；第一轮看到的「S14 偏少」是后备数据那一版的现象，现在没有了。
- **试过但没采用**：真实年份里让你的俱乐部照常从弱队买人（AI 转会只对你的队开放）——普通玩家联赛冠军 −2.4σ、MSI −2.3σ，强玩家任一冠军 +3.1σ，两头都更偏，否了。
- **顺手修掉的副作用**：第一版把「某队官宣裁掉首发」这条随机事件在真实年份整个拿掉，职业前少了一个涨粉 / 涨段位的来源，首年签约 .63 → .58；现在事件照发、奖励照给，只是不改名单，回到 .61。
