# 破局者 · The Breaker

英雄联盟电竞生涯模拟。你自建一名选手，从 17 岁打排位开始，在一个**会自己运转、自己变老、自己换血**的世界里，用 S12–S16 五年时间去终结 LCK 的统治。

一局约 **80–140 分钟**。

---

## 跑起来

```bash
npm start          # http://localhost:3000
```

改了源码之后要重新构建：

```bash
python demo/build.py
```

无头测试（跑完整一局生涯，不需要浏览器）：

```bash
npm test
```

## 这个项目的数据是真的

游戏里每一支队、每一名选手的数值，都是从真实比赛数据拟合出来的，不是手填的。

| 层 | 来源 | 规模 |
|---|---|---|
| 逐场表现 | Oracle's Elixir 2022/2023 | 150,348 行 × 165 列 |
| 逐赛季名单 | Leaguepedia | 35,534 行（含 LDL、LCK CL、NACL 等二队体系）|
| 选手档案 | Leaguepedia | 20,735 人，带中文名与生日 |
| 当前阵容 | Riot 官方电竞 API | 1,574 队 / 5,412 人 |

拟合出的队伍强度与真实战绩高度一致：T1 76.6（真实胜率 .745）、Gen.G 76.4（.760）、RNG 74.8（.640）、G2 65.0（.677）。

**年龄曲线用的是选手真实生日。**

### 五维怎么来的

在「同位置 × 同联赛层级」内做 z 标准化，再按出场数向联盟均值收缩（`g/(g+45)`，45 场算一半可信）。

| 维度 | 数据来源 | 与胜率相关 |
|---|---|---|
| 操作 | 15 分钟经济/经验/补刀差、DPM、伤害占比、多杀 | +0.461 |
| 运营 | 视野分/分钟、控制守卫、参团率、死亡占比、反野 | +0.215 |
| 心态 | 落后 2000 经济后的翻盘率、逆风数据保持度、决胜局表现 | +0.183 |
| 指挥 | **胜负贡献与个人数据的缺口** + 位置与年龄先验 | +0.486 |
| 体质 | 常规赛前后段衰减、单日连战保持度 | −0.010 |

**「指挥」为什么这么定义**：2022 年 Faker 的个人数据排在四大赛区第 149 位，但 T1 春季赛 18 战全胜、世界赛打进决赛。他那年打工具型中单，资源让给了队友——他的价值是让队友打得更好，而这件事不会出现在他自己的数据栏里。所以指挥在游戏里是**全队乘数**，不是个人属性。

### 能力与状态是两回事

能力取生涯水位，状态取当年表现。一个「能力 76 / 状态 30」的人是**正在低谷的强者**，不是废了的人。数据反推出的信号是真的：RNG 全队状态 30–32（那年常规赛确实划水）、V5 的 Rookie/Photic 状态 81（2022 春季黑马）、G2 的 Jankos 状态 80（那年 LEC 冠军）。

## 真人姓名

游戏使用真实选手与战队名。原则：

- 叙事只描述**赛果**，不描述真人的人格与心理——写「输了比赛」，不写「心态崩了被队友嫌弃」
- 名单是**可替换数据层**，换掉 `data/csv/game_data_2022.json` 即可整体切换为架空名
